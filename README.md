## Desapego Unifor

Bem-vindo ao repositório do **Desapego Unifor**, uma plataforma de economia circular desenvolvida para o ecossistema universitário. O projeto visa facilitar o desapego de materiais acadêmicos e objetos pessoais, promovendo a sustentabilidade e o acesso facilitado a recursos para estudantes.

## Tecnologias Utilizadas
- **Frontend:** React, Vite, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Banco de Dados:** Supabase
- **Deploy:** Vercel (Frontend), Render (Backend)

## Como rodar o projeto localmente

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (v18 ou superior recomendado)
- Gerenciador de pacotes (npm ou yarn)

### Instalação
1. Clone os repositórios:
```
- git clone https://github.com/luken6406/marketplace-frontend.git (FRONTEND)
- git clone https://github.com/luken6406/marketplace-backend.git  (BACKEND)
```
No terminal, acesse as pastas do frontend e backend (cd "endereço da pasta") e abra o VSCode com o código:

```
code .
```

você terá duas instâncias do VS Code abertas, em cada uma delas, abra um terminal e execute:
```
npm install
```
## Configure as variáveis de ambiente:

Na pasta frontend, crie um arquivo .env e adicione a URL do seu backend:
```
VITE_API_URL=http://localhost:3001
```
Certifique-se de configurar as credenciais necessárias para o Supabase no seu backend.

o arquivo .env no backend deve ter as seguintes variáveis:
```
MELHOR_ENVIO_TOKEN=(token do sandbox melhor envio, para calculo de frete)
SUPABASE_URL=(URL do banco)
SUPABASE_ANON_KEY=(Anon key do supabase)
```
Para criar as tabelas do Supabase, utilize este código SQL:
```
CREATE TABLE IF NOT EXISTS users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  cpf TEXT NOT NULL UNIQUE,
  cep TEXT NOT NULL,
  matricula TEXT NOT NULL UNIQUE,
  email TEXT NOT NULL UNIQUE,
  password TEXT NOT NULL
);


CREATE TABLE IF NOT EXISTS listings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  imgURL TEXT,
  category TEXT NOT NULL,
  price NUMERIC,
  isDonation BOOLEAN DEFAULT FALSE,
  description TEXT,
  userId BIGINT REFERENCES users(id) ON DELETE CASCADE,
  createdAt TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);


CREATE TABLE IF NOT EXISTS messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  listingId BIGINT REFERENCES listings(id) ON DELETE CASCADE,
  senderId BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  receiverId BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  text TEXT NOT NULL,
  createdAt TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);
```

## Execução
De acordo com as instruções de instalação, você terá duas instâncias do VSCODE aberto, para iniciar o front end e o back end, utilize o código:
```
npm run dev
```
no terminal do VSCode em ambas as instâncias.

## Diário de Bordo da IA
Neste projeto, a IA Generativa (Gemini e ChatGPT) foi utilizada como um copiloto técnico, acelerando a implementação de funcionalidades e auxiliando na arquitetura da solução.

**1. Ferramentas Utilizadas**
Gemini: Utilizado para a maior parte da lógica central e estruturação de componentes.

ChatGPT: Utilizado para consultas de dúvidas rápidas e refatoração de pequenos trechos.

**2. Estratégia de Engenharia de Prompts**
Exemplo 1: Refatoração de Componentes (Reaproveitamento de ListingForm)
Para reaproveitar o formulário de anúncio tanto para criação quanto para edição, utilizei o seguinte prompt:
```
"Faça esse botão redirecionar para a página "list" (CreateListing.tsx), onde o ListingForm.tsx receberá os dados do anúncio com os campos já preenchidos. O formulário deve aceitar uma prop 'method' (PUT ou POST) para definir o tipo de requisição. Ao enviar, use o navigate() para retornar ao perfil."
```
Exemplo 2: Estruturação da Landing Page
Para garantir um layout profissional sem depender de componentes aleatórios:
```
"Faça uma landing page com: Banner central com 4 imagens relacionadas ao 'Desapego Unifor' (economia circular). Abaixo, reutilize o componente ListingCard.tsx exibindo anúncios filtrados por categorias (eletrônicos, livros, etc.). Inclua um CTA claro: 'Crie sua conta gratuitamente'."
```
**3. Reflexão Crítica: Lidando com "Alucinações"**
Durante a implementação da paginação em Listings.tsx, a IA gerou um código com uma função inexistente (resHasTotalHeaderLogic), resultando em um erro de execução. A solução da IA parecia visualmente correta, mas logicamente falha e tecnicamente inválida.

**Como resolvi:** Em vez de tentar "remendar" o erro gerado, iniciei uma nova conversa, descrevi o problema de negócio (paginação dinâmica baseada no total de anúncios) e pedi sugestões de arquitetura ideal. A IA sugeriu então que o backend retornasse o total de registros, permitindo que o frontend calculasse o número de páginas dinamicamente. Esta experiência reforçou a importância de validar a lógica do backend antes de implementar o frontend.


### Conclusão

A utilização de IA acelerou o desenvolvimento do projeto, principalmente na criação, estruturação e refatoração de componentes. Entretanto, a experiência também mostrou que as sugestões geradas precisam ser analisadas e testadas antes de serem incorporadas ao sistema.

Os problemas encontrados durante o desenvolvimento reforçaram a importância de compreender a arquitetura da aplicação e validar a comunicação entre frontend e backend, utilizando a IA como ferramenta de apoio e não como substituta da tomada de decisões técnicas.
